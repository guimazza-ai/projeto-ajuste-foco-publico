# Projeto de Foco na Experiência do Usuário

## 🎯 Descrição do Desafio

O objetivo deste desafio foi **modificar o relatório financeiro**, desenvolvido em conjunto durante o curso da DIO, aplicando melhorias focadas na **experiência do usuário (UX)**. Para isso, foi necessário acompanhar o vídeo explicativo do desafio e adaptar o relatório considerando princípios de design e usabilidade.

---

## 🖌️ Conceitos Aplicados no Relatório

Durante a reformulação do relatório, foram levados em conta os seguintes pilares de design:

- **Posicionamento**
  - Organização estratégica dos visuais para facilitar a leitura e o fluxo de análise.

- **Contraste**
  - Uso adequado de cores e destaques para melhorar a legibilidade e evidenciar informações importantes.

- **Proporção Áurea**
  - Distribuição equilibrada dos elementos visuais na página, buscando harmonia e estética.

- **Segmentação dos Dados**
  - Utilização de segmentadores para permitir análises interativas e personalizadas.
